sequenceDiagram
    participant browser
    participant server

    Note right of browser: The user writes a note and clicks Save
    browser->>server: POST /exampleapp/new_note
    activate server
    Note right of server: The server saves the note
    server-->>browser: 302 Redirect to /exampleapp/notes
    deactivate server

    browser->>server: GET /exampleapp/notes
    activate server
    server-->>browser: HTML document containing the notes
    deactivate server

    browser->>server: GET /exampleapp/main.css
    activate server
    server-->>browser: CSS file
    deactivate server

    browser->>server: GET /exampleapp/main.js
    activate server
    server-->>browser: JavaScript file
    deactivate server

    Note right of browser: The browser displays the updated notes page
